# Safari 웹 리모컨

기존 아이폰 앱과 등록 정보는 유지합니다. 웹 연결을 선택하면 기존 제어 연결은 해제되고 한 번에 하나의 리모컨이 조작합니다.

## 처음 한 번

1. Mac에서 RemoteTVHost → 연결 및 설정 → **Safari 웹 리모컨** → **웹 리모컨 켜기**.
2. 아이폰 기본 카메라로 이 영역의 QR을 읽습니다. 기존 네이티브 앱의 ‘아이폰 등록’ QR과 다릅니다.
3. Safari 공유 메뉴에서 **홈 화면에 추가**합니다.
4. 홈 화면 아이콘으로 웹앱을 열고, Mac에 표시된 **6자리 웹 등록 코드**를 입력합니다. 코드는 2분마다 자동으로 바뀌고 한 번만 사용할 수 있습니다. 만료되었으면 Mac에 표시된 새 코드를 입력하세요.
5. 등록 직후 자동으로 Mac 연결을 시도합니다. 연결되면 Mac 화면에서 코드는 사라지고 연결 상태와 웹앱 식별 코드가 표시됩니다.

## 이후 사용

Mac과 RemoteForMac Host를 켜 두고 같은 Wi-Fi에서 홈 화면의 웹앱을 엽니다. 처음 한 번 등록했다면 자동으로 연결을 시도합니다. 수동으로 연결을 해제한 뒤에는 **이 Mac 연결**을 다시 눌러야 합니다. 인증키는 브라우저 저장소와 Mac Keychain에 보관합니다. 고정 포트 49373과 `remotetv.local` 이름을 사용하므로 Mac 앱 재시작마다 QR을 다시 읽지 않아도 됩니다. Mac에서 웹 리모컨을 켠 상태로 종료하면 다음 실행에서 자동으로 켭니다.

Mac에 네이티브 아이폰 앱이나 웹앱이 연결되어 있으면 웹 등록 코드는 숨겨지고 자동 갱신도 멈춥니다. 연결이 해제되면 새 코드가 생성됩니다.

Safari와 홈 화면 웹앱의 저장소가 분리되는 경우 각각 처음 한 번 등록해야 합니다. Safari 데이터 삭제, 웹 등록 초기화, 주소 변경 시에는 재등록 또는 주소 갱신이 필요합니다. 구형 시험판의 임시 포트 주소로 홈 화면 아이콘을 만들었다면 새 QR 주소로 아이콘을 한 번 다시 추가하세요.

## 터치패드와 입력

- 한 손가락 이동·탭 클릭, 두 번 탭 후 두 번째 접촉을 유지하며 이동하면 드래그.
- 두 손가락 스크롤·탭 오른쪽 클릭·벌리기/오므리기 핀치.
- 세 손가락 드래그, 네 손가락 쓸기와 펼치기/오므리기는 기존 앱의 Mac 제스처 판별 코드를 재사용합니다.
- 터치패드 상단 ‘스크롤 기본/스크롤 반대’ 버튼으로 즉시 방향을 바꿉니다. 홈 화면 설정과 함께 저장됩니다.
- Mac 입력창을 클릭한 뒤 터치패드 상단 키보드 버튼을 누릅니다. 웹 키보드 입력창의 글자가 Mac으로 전송됩니다.
- 다른 앱으로 이동·잠금 시 제어를 중단합니다. 돌아오면 저장된 등록 정보로 자동 재연결을 시도합니다. 통신이 사라지면 Mac은 최대 5초 안에 드래그와 입력 세션을 해제합니다.

## 연결 특성

Mac이 로컬 웹페이지를 제공합니다. 호스팅·도메인·Apple Developer Program 가입은 필요 없습니다. 이 버전은 **암호화되지 않은 HTTP**입니다. 개인용으로 신뢰하는 Wi-Fi에서 사용하고 공유기 포트 포워딩을 설정하지 마세요. 화면에도 해당 제한을 안내합니다. 웹 연결은 기존 앱의 TLS 연결과 별도입니다.

코드 시도 횟수를 제한하고, 등록한 브라우저 인증키가 없는 입력 요청·다른 Origin·허용되지 않은 Host·중복 입력 순서를 거부합니다. ‘웹 등록 초기화’는 등록한 모든 웹 브라우저의 인증키를 폐기하며 기존 아이폰 앱 등록에는 영향을 주지 않습니다.

전송은 TCP 지연을 끄고 HTTP 연결을 재사용합니다. 움직임은 화면 프레임 및 터치 이벤트에 맞춰 전송하고, 밀린 연속 움직임은 최신 좌표로 합칩니다. 실제 반응은 Wi-Fi·Safari·Mac 상태에 따라 달라집니다. HTTPS를 사용하지 않으므로 웹 카메라 API나 서비스 워커 같은 보안 컨텍스트 기능은 사용하지 않습니다.

## 검증

공통 Swift 테스트 80개와 별도 HTTP 서버·모바일 크기 Chrome 브라우저에서 코드 등록, 저장 후 새로고침 자동 연결, 인증 누락·다른 Origin 차단, 파일 경로 제한, 터치·한글 데이터 전송, 입력 재전송 거부, 방향 선택, 가로 배치를 확인했습니다. 테스트 서버는 실제 Mac 입력을 만들지 않습니다. 실제 아이폰 Safari의 키보드 조합·여러 손가락 인식·Mac 대상 앱 동작은 별도 실사용 확인이 필요합니다.

웹앱 이름은 **RemoteForMac**입니다. 기본 주소는 `http://remotetv.local:49373/`이며, 별칭을 사용할 수 없으면 Mac 이름 주소로 대체합니다. 새 이름과 리모컨 아이콘이 홈 화면에 반영되지 않으면 Safari에서 새 주소를 열어 홈 화면에 다시 추가하세요. 주소가 바뀌면 등록 코드 입력이 처음 한 번 필요합니다.
